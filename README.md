# OneRobotics A1 for PyBullet

PyBullet integration for the OneRobotics A1 right arm, left arm, and bimanual
stand. The source model is locked to
[`katazen/onerobot_h1`](https://github.com/katazen/onerobot_h1) commit
`ecf530911284ba0e559f7a24dc222fd8e60d31ed`.

Implementation is in progress. Final copy-paste setup, viewing, validation, and
publication instructions will be added after runtime verification.
